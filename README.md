# NoteCheck-PK — نوٹ اسکینر

پاکستانی کرنسی نوٹ کی تصویر اپلوڈ کرنے پر AI (OpenAI GPT-4o Vision) کے ذریعے نظر آنے والی
بصری خصوصیات کا جائزہ دیتا ہے۔ یہ ٹول حتمی اصلی/جعلی فیصلہ نہیں دیتا — صرف رسک لیول اور
مشاہدات دکھاتا ہے۔ حتمی تصدیق کے لیے ہمیشہ بینک یا اسٹیٹ بینک آف پاکستان سے رجوع کریں۔

## فائل اسٹرکچر

```
index.html          فرنٹ اینڈ (اپلوڈ فارم، مالیت سلیکٹر، نتیجہ دکھانا)
api/analyze.js       Vercel serverless function — OpenAI کو تصویر بھیجتا ہے
manifest.json         PWA manifest (ایپ کے طور پر انسٹال کے لیے)
sw.js                 Service worker (بنیادی کیشنگ)
icons/                ایپ آئیکنز (عام + maskable)
favicon.ico            براؤزر ٹیب آئیکن
robots.txt            سرچ انجن indexing کی اجازت
```

## سیٹ اپ

1. Vercel پر پروجیکٹ deploy کریں (یا موجودہ "note-check-pk" پروجیکٹ استعمال کریں)۔
2. Environment Variable سیٹ کریں:
   - `OPENAI_API_KEY` — OpenAI کی API key (GPT-4o Vision تک رسائی کے ساتھ)
3. کوئی build کمانڈ درکار نہیں — یہ static + serverless function پروجیکٹ ہے۔

## اپڈیٹ کرنے کا طریقہ

فائلیں GitHub repo میں (سابقہ فائلوں کی جگہ) تبدیل کریں، commit اور push کریں —
Vercel خودکار طور پر نیا ورژن deploy کر دے گا۔

## اہم نوٹس

- تصویر صرف تجزیے کے لیے OpenAI کو بھیجی جاتی ہے، سرور پر محفوظ نہیں کی جاتی۔
- تصویر بھیجنے سے پہلے براؤزر میں resize/compress کی جاتی ہے (413 ایرر سے بچنے کے لیے)۔
- روشنی کے سامنے کی اضافی (اختیاری) تصویر AI کو واٹر مارک اور سیکیورٹی تھریڈ بہتر جانچنے میں مدد دیتی ہے۔
